# Technical notes

Setup, demo and presentation instructions are in the main [README](../README.md).

## EV BMS cyber-attack simulation (MATLAB)

Minor project: *Cybersecurity and Anomaly Detection in EV Battery Management Systems*,
Dept. of Electrical Engineering, MNIT Jaipur.

## Run

1. Open MATLAB (R2020a or newer, or MATLAB Online), `cd` into this folder.
2. Type `main` and press Enter.
3. Figures, `summary.csv` and the trained model appear in `results/`.

Step 3 (ML classifier) needs the Statistics and Machine Learning Toolbox. Without it the
script skips that step and everything else still runs. Set `RUN_ML = false` in `main.m`
for a quick run (about 15 s instead of 2-3 min).

## What is simulated

```
 battery (4S Li-ion, Thevenin model + thermal)
    -> sensors (noise, ADC resolution)
    -> communication channel      <-- attacker: FDI, spoofing, replay, jamming, timestamps
    -> BMS: EKF SoC estimator + 8 detectors
    -> CC-CV charge control
    -> charger                    <-- attacker: firmware tampering
    -> battery
```

Each attack is run twice from the same random seed:
- **no defence**: detectors only watch. This shows what the attack does to the battery
  (overcharge, temperature, wrong SoC).
- **with defence**: on an alarm the BMS ramps the current to zero and opens the contactor.

The basic BMS range check (trip above 4.25 V or 50 °C) is active in both runs, as in a
real BMS. It shows why range limits alone are not enough.

## Detection layer

| Detector | Idea | Catches |
|---|---|---|
| Pack vs sum of cells | separate pack sensor must equal sum of cell voltages | FDI, frozen cell |
| Current vs command | measured current must follow what the BMS asked for | firmware tampering |
| EKF voltage residual | measured voltage vs model prediction (Kalman innovation) | FDI, replay, frozen |
| Frozen value | identical readings while current flows | spoofing (freeze) |
| Noise level | rolling std of sample-to-sample change | noise / EMI, replay jump |
| Freshness counter | MAC-protected message counter must increase | replay |
| Timestamp check | time between frames must match counter step | timestamp attack |
| Link timeout | 3 missed frames in a row | jamming / DoS |

Thresholds are set **only from attack-free runs** (`calibrate_thresholds.m`): 1.5 x the worst
value seen in normal charging.

The ML stage trains boosted decision trees (`fitcensemble`, AdaBoostM2, the MATLAB
counterpart of XGBoost) on 96 runs with random attack type, start time and strength. It is
tested on runs it never saw.

| `main.m` | runs everything |

## Simulink / Simscape version

`main_simulink.m` runs the same study on a Simulink model, `simulink/EV_BMS_Simscape.slx`
(needs Simulink + Simscape). The model is generated by `simulink/build_ev_bms_model.m`, so
it can always be rebuilt from code.

| Block | Domain | What it is |
|---|---|---|
| Battery pack and charger | Simscape | 4 x `li_cell` + `current_charger`, custom Simscape-language components in `simulink/+evbms/` |
| Charger control | Simulink | charger firmware (tamper point) -> current loop (1/(2s+1)) -> contactor |
| Sensors (ADC) | Simulink | 1 s sampling, Gaussian noise, ADC rounding |
| Communication channel (attacker) | Simulink | all channel attacks (`attack_step.m`) |
| BMS (EKF + IDS + CC-CV) | Simulink | EKF, 8 detectors, charge control, fail-safe (`bms_step.m`) |
| Data logging | Simulink | To Workspace blocks |

`li_cell.ssc` writes the cell physics as equations: OCV(SoC) table, R0, R1||C1, coulomb
counting, lumped thermal with overcharge heat. Open it to show the model in the viva.

To open the diagram: `open_system('simulink/EV_BMS_Simscape')`.
Results (plots, `summary_simulink.csv`, `script_vs_simulink.csv`, diagram PNGs) go to
`results_simulink/`. Simulink and script results agree within 0–2 s for detection time and
0.04 V for peak cell voltage.

## Limits (say these in the viva)

- Cell parameters are typical NMC 18650 values, not measured on our own cell.
- The overcharge heat term is a simple illustration, not a validated abuse model.
- A slow, carefully coordinated attacker who changes both the cell and the pack readings
  consistently would beat the pack check; the EKF residual and the ML model are the next line.
